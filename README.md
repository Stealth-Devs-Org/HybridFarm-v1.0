# 🌱 Hybrid Farm v1.0

**Hybrid Farm** is a game developed for the **Software Design Competition (EN3350)** module, Semester 6, at the **University of Moratuwa**.  
This repository contains the source code and related assets for the project.

## 🎮 About the Game
Hybrid Farm is a simulation-based game that blends strategic farming mechanics with engaging gameplay elements.  
The project was developed as part of an academic software design challenge, focusing on creativity, system design, and implementation quality.
