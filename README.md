🌱 Hybrid Farm v1.0

Hybrid Farm is an open-source, simulation-based game that blends strategic farming mechanics with engaging gameplay elements.
The project was developed as part of an academic software design challenge, focusing on creativity, system design, and implementation quality.

This project is released to support learning, collaboration, and community-driven development, especially for those interested in Unity Game Development.
